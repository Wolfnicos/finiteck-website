# Finiteck website

## Register

brand

## Users

iPhone and iPad owners who want to understand recurring expenses and find practical ways to spend less. The existing homepage is English; the existing guides and journal are French. Preserve both audiences and clearly label the French resources.

## Product purpose

Explain Finiteck, show the real app, help visitors understand its local storage and optional cloud AI, and take interested visitors to the existing App Store listing. Keep support, privacy, terms, risk information, and all existing article URLs accessible.

## Brand personality

Composed, precise, encouraging. Continue the existing charcoal and gold identity and app icon. Show useful product details instead of invented customer counts, testimonials, or savings guarantees.

## Anti-references

The current small centered hero, repetitive icon-card grids, gradient headings, and oversized navigation link list obscure the app. Avoid those patterns. Avoid investment-platform aesthetics and promises of guaranteed returns.

## Design principles

1. Show real App Store screenshots before asking someone to download.
2. Make recurring costs tangible with a clearly labelled, browser-local calculator.
3. Explain local storage and consent-based cloud features accurately.
4. Keep navigation, reading, and pricing clear on a small screen.
5. Preserve the static HTML/CSS stack and existing URLs.

## Accessibility and inclusion

Target WCAG 2.2 AA contrast, semantic headings, native controls, visible keyboard focus, reduced-motion support, readable content measures, and useful no-JavaScript fallbacks. Do not imply a completed accessibility certification.

## Evidence

Derived from README.md, the existing website, privacy.html, the sibling app documentation, and the public App Store listing reviewed on 2026-10-09. This is an implementation record for the user's requested complete redesign.
