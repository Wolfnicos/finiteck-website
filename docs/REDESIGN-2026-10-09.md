# Finiteck redesign · 9 October 2026

## Implemented

The static site now has a coherent charcoal-and-gold visual system, self-hosted Manrope typography, an asymmetric product hero, real App Store screenshots, a screen selector, a browser-local recurring-cost calculator, clear subscription cards, and a shared header/footer.

The French guide library and journal were reorganised. All 23 journal articles remain discoverable through search and category filters. Search ignores accents. Generated article headers now show their own titles and dates rather than the unrelated template title. Each content page has one h1. Guides and articles have readable content widths, scrollable tables, desktop contents navigation, and a reading-progress line.

Support now explains consent-based cloud features, subscription management, data export, and all four app languages. The homepage no longer claims that optional cloud AI never sends any data. A custom 404 and static-site check scripts were added.

## Preserved

The original stack, GitHub Pages domain configuration, verification files, legal-policy wording, guide/article paragraphs, public content URLs, existing external image sources, and existing analytics integration were retained. No iOS application files were changed. No production deployment was performed.

## Limits

Responsive previews were rendered by desktop Chrome, not physical iOS devices. This was a redesign and functional check, not an independent legal review, a factual re-verification of every archived article, or a formal WCAG certification. Existing policy and article copy remains the owner's content.

## Maintenance

Run `python3 scripts/build_css.py` after stylesheet edits. Run `python3 scripts/check_site.py` and `node --check js/site.js` before publication. `PRODUCT.md`, `DESIGN.md`, and `images/SOURCES.md` record the chosen direction and asset provenance.
